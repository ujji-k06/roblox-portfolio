About

The work behind the game.

I'm ujji_k06. I work across Roblox gameplay and the systems around it: combat, traversal, data, UI, and server-side networking. I care about how a mechanic feels to play and how easy it is to maintain.

I've been freelancing on Roblox since 2022. More recently, I've published tools for measuring remote activity and catching Rojo project errors. The code is public, so you can see how I approach problems as well as the results.

A CLI that catches missing paths, child collisions, and ambiguous init files in Rojo projects before a build. Readable diagnostics, JSON output, and CI-friendly exit codes.
